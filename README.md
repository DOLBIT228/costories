# 💍 CoStories — генератор кошторису обручок

Вебзастосунок для менеджерів та адміністраторів ювелірної компанії, який допомагає:

- швидко розрахувати кошторис пари обручок (жіноча + чоловіча);
- керувати прайсами на метали, роботу, каміння, профілі, гравіювання та покриття;
- сформувати брендований PDF-кошторис (з фоном, фото, кольором тексту, деталізацією цін);
- експортувати документ у JPG (за наявності підтримки `pypdfium2` у середовищі).

Проєкт побудований на **Streamlit + SQLite**, тому підходить для швидкого локального запуску та простого деплою.

## Функціональність

### Для менеджера

- Розрахунок двох виробів одночасно: **жіноча** та **чоловіча** каблучки.
- Ввід параметрів: розмір, ширина, товщина, вага, метал, тип роботи.
- Додавання опцій:
  - каміння (тип, розмір, кількість);
  - профіль;
  - гравіювання;
  - покриття;
  - поєднання кольорів.
- Застосування знижок:
  - фіксована знижка на метал у ₴/г;
  - відсоткова знижка на роботу ювеліра;
  - відсоткова знижка на профіль;
  - відсоткова знижка на гравіювання.
- Перегляд деталізованої таблиці ціноутворення по кожній каблучці.
- Ввід даних для договору (імена пари, номер угоди).
- Експорт результату у PDF та JPG.

### Для адміністратора

- Редагування довідників цін через таблиці:
  - `metals`, `jeweler`, `stones`, `profiles`, `engravings`, `coatings`.
- Керування курсом USD:
  - ручний ввід;
  - автооновлення з API НБУ.
- Налаштування стилю PDF:
  - колір тексту та ліній (`HEX`);
  - завантаження нових фонів (`PNG/JPG`);
  - вибір активного фону.

## Технологічний стек

- **Python 3.10+**
- **Streamlit** — UI та вебзастосунок
- **SQLite** — локальна БД
- **Pandas** — робота з таблицями
- **ReportLab** — генерація PDF
- **Pillow** — обробка зображень
- **pypdfium2** — конвертація PDF → JPG
- **requests** — оновлення курсу USD з НБУ

## Швидкий старт

### 1) Клонування та встановлення залежностей

```bash
git clone <your-repo-url>
cd costories
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 2) Налаштування секретів Streamlit

Створіть файл `.streamlit/secrets.toml`:

```toml
[auth]
admin_username = "admin"
admin_password = "strong_admin_password"
manager_username = "manager"
manager_password = "strong_manager_password"
session_duration_hours = 12
# session_secret = "optional_extra_secret"
```

> Якщо `session_secret` не вказаний, підпис токена формується з паролів admin/manager.

### 3) Запуск

```bash
streamlit run app.py
```

Після першого старту застосунок сам ініціалізує структуру БД (`init_db()`).

## Налаштування доступу (логін/пароль)

Авторизація побудована на двох ролях:

- `admin` — повний доступ до вкладок **Менеджер** + **Адмін**;
- `manager` — доступ лише до вкладки **Менеджер**.

Сесія зберігається через підписаний токен у query-параметрі (`auth`) з полями:

- `role`
- `iat` (час видачі)
- `exp` (час завершення)

Підпис — `HMAC-SHA256`.

## Ролі та сценарії роботи

### 1) Базове налаштування (адмін)

1. Увійдіть під `admin`.
2. Заповніть ціни у таблицях довідників.
3. Встановіть курс USD (вручну або «Оновити з НБУ»).
4. Оберіть фон і колір PDF.

### 2) Щоденна робота (менеджер)

1. Увійдіть під `manager`.
2. Заповніть параметри обох каблучок.
3. Додайте необхідні опції (каміння, профіль, гравіювання, покриття).
4. За потреби застосуйте знижки.
5. Введіть дані для договору.
6. Згенеруйте PDF/JPG і віддайте клієнту.

## Логіка розрахунку

Підсумок для кожної каблучки складається з рядків ціноутворення:

- **Метал**: `ціна_за_грам * вага` мінус знижка в ₴/г (одиничне віднімання для позиції металу).
- **Робота ювеліра**: `ціна_за_грам * вага` з відсотковою знижкою.
- **Каміння**: ціна в USD з матриці `stones` множиться на курс `settings.usd`.
- **Профіль/гравіювання/покриття**: фіксована ціна за позицію (знижка для профілю/гравіювання — %).
- **Поєднання кольорів**: довільна сума як окрема послуга.

Загальна сума пари = сума жіночої + сума чоловічої.

## Генерація PDF/JPG

### PDF

Документ включає:

- фонове зображення з `assets/backgrounds`;
- 1 або 2 фото каблучок у верхній частині;
- таблицю параметрів (розмір, ширина, товщина, вага);
- таблицю ціноутворення по обох каблучках;
- блок «Загальна вартість»;
- футер із даними договору (за наявності).

При великій кількості рядків застосовується компактний режим верстки (менші шрифти/відступи), щоб вмістити все на сторінку A4.

### JPG

Після створення PDF застосунок намагається конвертувати 1-шу сторінку в JPG.
Якщо середовище не підтримує рендеринг (або бракує залежностей), користувач отримує попередження, а PDF лишається доступним.

## База даних та ініціалізація

`database.py` створює (або доповнює) таблиці:

- `metals`
- `jeweler`
- `settings`
- `stones`
- `profiles`
- `engravings`
- `coatings`

Також виконується:

- міграція старих назв типів ювеліра (`platinum/premium/premium_plus` → `Платина/Преміум/Преміум+`);
- нормалізація `settings.background_file`;
- валідація/нормалізація `settings.text_color` до коректного HEX.

## Практичні поради з експлуатації

- Зберігайте `data.db` у резервній копії (особливо перед оновленнями).
- Для продакшену використовуйте надійні паролі у `secrets.toml`.
- Якщо шрифти `e-Ukraine` недоступні, система пробує `Montserrat` як fallback.
- Підготуйте декілька фірмових фонів у `assets/backgrounds`, щоб швидко перемикати стиль КП.
